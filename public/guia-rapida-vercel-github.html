Guía rápida

Publicar tu Primer Frontend en Vercel usando GitHub

Esta guía resume los pasos para publicar un sitio estático en Vercel partiendo de un repositorio en GitHub.

0. Prerrequisitos

  • Cuenta en GitHub (ej. https://github.com/tu-usuario).
  • Cuenta en Vercel (puedes iniciar sesión con GitHub).
  • Git instalado en tu equipo.
  • Un editor de código (VS Code, por ejemplo).

1. Crear el repositorio en GitHub

  1. Entra a GitHub y haz clic en New repository.
  2. Asigna un nombre, por ejemplo: deployment-frontend-backend.
  3. Déjalo como Public y no marques opciones para crear README, .gitignore ni License.
  4. Haz clic en Create repository.

GitHub mostrará la URL del repo, por ejemplo: https://github.com/tu-usuario/deployment-frontend-backend.git

2. Crear el proyecto localmente

  1. Crear la carpeta y entrar en ella: 
    mkdir deployment-frontend-backend
cd deployment-frontend-backend
  2. Inicializar git: 
    git init
  3. Ejemplo de index.html básico: 
    <!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <title>Hola, Vercel</title>
</head>
<body>
  <h1>¡Hola, Vercel!</h1>
  <p>Proyecto web básico listo para desplegar.</p>
</body>
</html>
  4. Primer commit: 
    git add .
git commit -m "feat: proyecto web básico para Vercel"

3. Conectar el proyecto con el repositorio remoto en GitHub

Agregar el remoto y hacer push a main:

git branch -M main
git remote add origin https://github.com/tu-usuario/deployment-frontend-backend.git
git push -u origin main

4. Importar el repositorio en Vercel

  1. Visita https://vercel.com/new e inicia sesión.
  2. Conecta tu cuenta de GitHub y autoriza el repositorio deployment-frontend-backend.
  3. Selecciona el repositorio y haz clic en Import.

5. Configurar y desplegar en Vercel

  • Project Name: puedes dejar el nombre por defecto.
  • Framework Preset: selecciona Other o Static Site.
  • Root Directory: la raíz del repo (donde está index.html).
  • Build Command y Output Directory: vacíos (sitio estático).

Haz clic en Deploy. Vercel generará una URL pública del estilo:
https://deployment-frontend-backend.vercel.app/

6. Actualizar el contenido

Para cambiar la página principal puedes reemplazar directamente index.html o hacer que redirija a otro archivo. Ejemplo de redirección en index.html: 

<meta http-equiv="refresh" content="0; url=guia-rapida-vercel-github.html">

7. Flujo de trabajo diario

  1. Editar archivos en tu proyecto.
  2. Ejecutar: 
    git add .
git commit -m "mensaje de los cambios"
git push
  3. Vercel redepliega automáticamente la última versión.

8. Próximos pasos

  • Usar frameworks como React o Next.js.
  • Agregar Tailwind CSS para estilos modernos.
  • Integrar variables de entorno y backends (OCI, Render, Fly.io, etc.).

Esta guía cubre el flujo mínimo para publicar un frontend estático en Vercel usando GitHub como origen del código.
