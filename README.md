# Proyecto Web Básico para Vercel

Este proyecto es una plantilla mínima para desplegar en Vercel.

## Estructura
- `/public`: Archivos estáticos (imágenes, favicon, etc.)
- `/src`: Código fuente (JS, CSS, etc.)
- `index.html`: Página principal
- `vercel.json`: Configuración opcional para Vercel

## Despliegue
1. Sube este repositorio a GitHub.
2. Conéctalo a Vercel y selecciona como proyecto estático.
3. ¡Listo!
