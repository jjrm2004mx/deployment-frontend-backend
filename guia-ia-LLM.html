01 · FundamentosEntrenamiento de LLM: Autosupervisado → SFT → RLHF

Visión de 3 etapas

  1. Preentrenamiento autosupervisado (Pretraining): el modelo aprende lenguaje a gran escala prediciendo la siguiente palabra/fragmento. Usa un corpus amplio y diverso. Resultado: modelo base con conocimiento general pero sin estar alineado.
  2. SFT (Supervised Fine-Tuning): se entrena con pares instrucción → respuesta de alta calidad para enseñar formato, estilo y cumplimiento de instrucciones. Resultado: modelo instruccional.
  3. RLHF (Reinforcement Learning from Human Feedback): se entrena un modelo de recompensa (RM) con preferencias humanas y luego se optimiza la política del LLM (p.ej., con PPO o DPO) para maximizar utilidad y seguridad. Resultado: modelo alineado.
💡
Modelo mental:

Pretraining = conocimiento · SFT = formato/obediencia · RLHF = conducta/valores.

Detalles operativos

  • Calidad de datos: limpieza, deduplicación, filtrado de toxicidad, licencias y curación.
  • Tokenización estable: define vocabulario y controla cambios entre fases.
  • Conjuntos de evaluación: automáticos y humanos para before/after en cada etapa.
  • Seguridad y cumplimiento: políticas de seguridad, guardrails y auditoría en todo el pipeline.
  • Observabilidad: monitoreo de calidad, sesgo, toxicidad, y drift post-despliegue.

Variantes modernas

  • DPO: optimiza con preferencias directas, simplificando la etapa de RM/PPO.
  • RLAIF: usa feedback de modelos alineados cuando el humano es costoso.
  • LoRA/PEFT: fine-tuning eficiente en parámetros para dominios/estilos específicos.
  • Distillation: transferir comportamiento de un modelo grande a uno más pequeño.

02 · GlosarioGlosario corto (reutilizable)

Conceptos clave

Término Definición
Token Unidad de texto que procesa el modelo; depende del tokenizador.
Tokenizador Algoritmo que divide texto en tokens usando un vocabulario.
Ventana de contexto Cantidad máxima de tokens que el modelo puede leer por solicitud.
Prompt Texto de entrada para guiar la respuesta del LLM.
Instrucción Forma específica de prompt que indica claramente la tarea.
Corpus/Dataset Conjunto de datos usado para entrenar o evaluar.
Preentrenamiento Aprendizaje autosupervisado a gran escala para adquirir conocimiento general.
SFT Ajuste supervisado con pares instrucción→respuesta para obediencia/estilo.
RLHF Refuerzo con feedback humano; alinea conducta con valores/criterios.
DPO Optimización por preferencias directas, alternativa simplificada a PPO.
RLAIF Usa modelos alineados como jueces cuando escasea el etiquetado humano.
Modelo de recompensa (RM) Modelo que puntúa respuestas según preferencias o políticas.
Política Parámetros del LLM que generan respuestas; lo que se optimiza en RL.
LoRA/PEFT Técnicas para ajustar pocos parámetros y reducir costos.
Embeddings Vectores que representan significado; base de búsqueda semántica y RAG.
Vector store Índice/BD para almacenar y consultar embeddings por similitud.
RAG Recuperación + generación: aporta contexto externo antes de responder.
Temperatura Controla aleatoriedad en generación (0 = determinista, 1 = creativo).
Top-k / Top-p Estrategias de muestreo que limitan las opciones al generar texto.
Hallucination Respuesta plausible pero incorrecta; se mitiga con datos, RAG y guardrails.
Evals Conjuntos/pruebas para medir calidad, seguridad y regresiones.
Data leakage Contaminación: cuando los datos de evaluación aparecen en entrenamiento.
Chunking Partir documentos en fragmentos coherentes para embeddings/RAG.
Metadata Atributos adjuntos a fragmentos: origen, permisos, fecha, versión.

03 · ResumenResumen visual del pipeline

Datos en bruto
  → Limpieza · Deduplicación · Filtros de seguridad/licencias
  → Preentrenamiento autosupervisado (LM)
  → Modelo base

Instrucciones de calidad (pares instrucción→respuesta)
  → SFT (supervised fine-tuning)
  → Modelo instruccional

Preferencias humanas (comparaciones A/B, criterios de utilidad y seguridad)
  → Etiquetado · Curación
  → Modelo de recompensa (RM)
  → RLHF (PPO/DPO) sobre la política
  → Modelo alineado

Evaluación integral
  → Evals automáticos + revisión humana
  → Pruebas de seguridad/guardrails · Sesgo · Toxicidad

Despliegue y operación
  → Serving/API · Monitoreo de calidad/drift · Trazabilidad
  → Plan de actualización continua (datos, SFT, RLHF)
